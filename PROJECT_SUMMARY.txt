PROJECT OVERVIEW:
A production-grade, from-scratch QR code (versions 1–40, all 4 EC levels, 3 modes)
and Code128 barcode library for JavaScript/TypeScript. Fully specified, validated
against independent decoders, styled SVG rendering with templating, i18n (11
languages), browser camera scanning, and ready for deployment to npm, Docker,
GitHub Pages, and shared hosting.

DELIVERABLES:

┌─ Core Encoding (src/core/)
│  ├─ qr/encoder.ts          — Public QR API: encodeQR(text, options)
│  ├─ qr/matrix.ts           — Module placement, masking, penalty scoring
│  ├─ qr/segments.ts         — Text segmentation (numeric/alphanumeric/byte)
│  ├─ qr/reed-solomon.ts     — GF(256) error correction, EC codeword generation
│  ├─ qr/tables.ts           — ISO/IEC 18004 spec constants (verified)
│  └─ barcode/code128.ts     — Code128 subset B/C encoding (verified)
│
├─ Rendering & Styling (src/render/)
│  ├─ svg.ts                 — QR → SVG with 6 built-in templates
│  └─ barcode-svg.ts         — Code128 → SVG with configurable appearance
│
├─ i18n (src/i18n/)
│  └─ index.ts               — Message catalogs in 11 languages (en, id, es,
│                               fr, de, pt, ja, zh, ar, ru, hi)
│
├─ Capture & Scanning (src/capture/)
│  └─ camera.ts              — Browser camera wrapper using native BarcodeDetector
│
└─ Public API (src/index.ts) — Re-exports all public interfaces

HONEST SCOPE NOTE:

What ships:
  ✓ Complete QR encoder (spec-verified)
  ✓ Complete Code128 encoder
  ✓ Styled SVG rendering
  ✓ i18n scaffolding
  ✓ Camera scanning wrapper (requires native BarcodeDetector)
  ✓ Full TypeScript types
  ✓ Zero runtime dependencies

What doesn't (see ROADMAP.md):
  ✗ Pure-JS camera decoder (finder detection, perspective correction)
  ✗ Native Java/Go/Rust/Python ports (each needs its own spec-compliance audit)
  ✗ Canvas/PNG renderer (use SVG or rasterize externally)
  ✗ Kanji mode or mixed-mode segmentation (rarely needed, adds complexity)
